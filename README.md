# Maverics
Plan is to develop the game about space maverics for any Apple device.
Start work on develop tower defence engine, which will be used in missions in this game.
Used SpriteKit, GamePlayKit.
Hard work on pathfinding for enemies, to avoid obstacles and move on the center of path to base.
That add in game ability to player to make a maze with blocks and traps.
